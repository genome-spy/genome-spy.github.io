Clustered Heatmap with Dendrograms¶

This example combines a heatmap with clustering trees on both axes and aligned row annotations. It displays expression for 72 genes across 60 cancer cell lines from ten lineages. Shared index scales keep the matrix, dendrogram leaves, labels, and annotation strips aligned while panning and zooming.

Data: Broad DepMap (2024), DepMap 24Q4 Public, licensed under CC BY 4.0. GenomeSpy hosts a processed demonstration subset of 60 cell lines and 72 protein-coding genes, with gene-wise standardization, computed Ward trees, and extracted cell-line annotations. The reproducible recipe records selection and processing; the data notice accompanies the mirrored extract.

Reading the heatmap¶

Rows are cell lines and columns are genes. Red indicates expression above a gene's mean across the selected cell lines; blue indicates expression below that mean. The values are z scores of the supplied log2(TPM + 1) expression, so the colors emphasize each gene's variation across cell lines. The color scale saturates at ±2.5, while tooltips retain the full numeric range.

The trees group similar expression profiles. Branch colors and gaps identify four row groups and six gene groups cut from the hierarchies. These groups are derived from expression and can span multiple cancer lineages. The three annotation strips show cancer lineage, growth pattern, and primary/metastatic sample origin. Gray sample-origin cells indicate unknown values.

Zooming and panning fit each tree's height scale to links whose two index anchors are inside the visible range. Local branches can then use the available panel space. Branches extending beyond the fitted height domain are clipped.

Preparing the data¶

GenomeSpy does not perform clustering. This visualization loads a wide expression matrix, cell-line and gene metadata tables, and a precomputed tree for each axis. The metadata links stable identifiers to labels, annotations, and zero-based row or column positions; tree records contain node IDs, parent IDs, and merge heights.

These files can be prepared with tools such as SciPy or R. Filter and normalize the matrix as appropriate, cluster rows and columns, and choose a leaf order. Export each hierarchy with identifiers that match the matrix and metadata, then assign leaf positions in the chosen order. Optional hierarchy cuts can supply branch groups and gap positions.

The reproducible recipe shows how these inputs were prepared for this example, using gene-wise z scores, Euclidean distance, Ward linkage, and optimal leaf ordering.

How the views stay aligned¶

The wide expression matrix is unfolded with regexFold. lookup joins the cell-line and gene metadata to the matrix and assigns the same leaf positions to each tree. The dendrogram transform converts the precomputed hierarchy into edges for orthogonal link marks.

The surround operator places the gene tree above the heatmap, the cell-line tree to its left, and the annotations and labels to its right. The matrix and gene tree share an x index scale; the matrix, cell-line tree, labels, and annotation strips share the y scale. Each tree retains an independent quantitative merge-height scale. Its height domain uses viewport autoscaling with mode: "contain". The dendrogram's fractional offsets are converted to pixels with bandstep(), keeping branches connected as the view changes size or zoom level. Explicit gapPositions on the index scales separate the chosen hierarchy groups.

The annotation strips use native bottom view titles with a shared named style. Their reserved bottom overhang leaves room for the rotated titles and gene labels. Collected legends place the expression ramp and categorical keys below the complete composition and wrap on narrow canvases.
