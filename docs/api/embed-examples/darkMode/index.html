Light and dark mode

Change the appearance of one running visualization. System follows your browser’s preference; Light and Dark override it. Custom shows how CSS properties can customize GenomeSpy’s default colors. This page opts into both modes with color-scheme: light dark.

Scroll over the plot to zoom and Shift-drag to brush a region, then switch appearance. Zoom and selection stay in place. Data colors stay the same. Titles, guides, grid lines, and legend text update; the transparent canvas reveals the page’s background.
