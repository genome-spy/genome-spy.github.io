Analyze brushed records

GenomeSpy loads ten generic measurements. Shift-drag across the plot to choose input records, then calculate each group's count and mean.

Analysis results received by the app


        

            view.data.transform({scope, transform, inputLimit,
                limit})
            captures brushed records first, then runs an aggregate
            transformation in a separate dataflow. The plot keeps its original
            measurements. The app receives summaries without repeating the
            calculation.
