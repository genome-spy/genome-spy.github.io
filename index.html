GenomeSpy

Interactive visualization for genomic and other data.

Create custom plots and genome browsers for web applications and Python notebooks. Explore individual genomic regions or compare data across samples.

GenomeSpy uses a visualization grammar to bring variants, signals, sequences, and annotations together in views that share genomic coordinates. Embed a custom browser in a web application, build interactive plots in Python notebooks, or explore data in Observable.

Use GenomeSpy to explore questions in cancer genomics, gene regulation, and sequence-to-function analysis. Browse examples of structural variants, sequence alignments, scatter plots, and heatmaps, or compare sample collections in GenomeSpy App.

Try the viewer below. Zoom from a whole-genome overview down to individual bases and see how DNA sequence, gene annotations, GC content, and evolutionary conservation line up. GPU-accelerated rendering keeps zooming and panning smooth, even with large datasets.

Build your own visualizations

GenomeSpy uses a declarative grammar: you describe the data, how it should be displayed, and how views fit together. The grammar builds on ideas from the Grammar of Graphics, ggplot2, and Vega-Lite, with features for genomic coordinates and data.

If you use IGV or the UCSC Genome Browser, the tracks above will look familiar. In GenomeSpy, you can design each track by choosing its marks, mapping data values to color or size, and layering marks in the same view. For example, draw arcs between structural variant breakpoints and align them with a track showing copy-number changes.

Use GenomeSpy in your work

In web applications

Embed a genome browser or interactive plot with the JavaScript API. Use GenomeSpy Core's declarative grammar to define custom views for your application.

In Python notebooks

Build charts from data frames with the Altair-like Python API. Explore gene expression heatmaps or scatter plots of single-cell embeddings in Jupyter or marimo.

Across sample collections

Compare samples and group them by metadata in GenomeSpy App. Inspect somatic mutations and gene amplifications in tumors, or explore DNA methylation and histone ChIP-seq signals.

Explore sample collections with GenomeSpy App

GenomeSpy App lets you explore genomic data from multiple samples together with sample metadata. It supports copy-number alterations, structural variants, mutations, DNA methylation, and signals from assays such as ATAC-seq and ChIP-seq. You can move from an overview of the sample collection to individual samples and genomic regions.

Samples can be filtered, grouped, and sorted using metadata or attributes derived from the genomic data—for example, copy number at a gene of interest. You can bookmark the resulting views and share them as URLs.

The App builds on GenomeSpy Core, so its views can be configured for different datasets and combinations of data types.
